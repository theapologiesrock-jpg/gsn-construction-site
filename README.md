# GSN Construction LLC — Website

Landing page for GSN Construction LLC (Seattle, WA). Vite + React + TypeScript + Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This repository is connected to Vercel. Pushes to `master` deploy automatically to production:
https://gsnconstruction-test.vercel.app
